


## 🧠 আগে জানো: Microprocessor মানে কী?
Microprocessor = Micro (ক্ষুদ্র) + Processor (প্রসেস করে)
👉 Microprocessor মানে একটা ছোট CPU —
একটা ছোট চিপ, যেটা data নেয়, হিসাব করে, আর output দেয়।

---

## 🔷 8085 Microprocessor Overview

👉 এইটা **Intel** কোম্পানির বানানো ৮-বিট মাইক্রোপ্রসেসর।
এর আগে ছিল:

* **4004** (4-bit, ক্যালকুলেটরে ব্যবহৃত, 1971)
* **8080** (8-bit, কিন্তু দুইটা পাওয়ার লাগতো)
* তারপর আসলো **8085**, যা একটাই পাওয়ার (+5V) দিয়ে চলে, তাই জনপ্রিয় হল।

---

## ⚙️ 8085 এর প্রধান বৈশিষ্ট্য (Main Features)

### ✅ 1. 8-bit Parallel Processing

👉 প্রসেসর একসাথে 8-bit মানে 1 byte ডেটা প্রক্রিয়াজাত করতে পারে।

**উদাহরণ:**
A = 10101100 (8-bit) → এইটা ALU তে গিয়ে যোগ, বিয়োগ, তুলনা ইত্যাদি হয়।

---

### ✅ 2. Single +5V Power Supply

👉 এটা চালাতে শুধু ৫ ভোল্ট বিদ্যুৎ লাগে।
আগের 8080 তে ছিল ২টা আলাদা পাওয়ার!

---

### ✅ 3. Clock Speed

👉 8085A এর গতি: 3 MHz
👉 8085A-2 এর গতি: 5 MHz

মানে প্রতি সেকেন্ডে ৩ মিলিয়ন বা ৫ মিলিয়ন কাজ করতে পারে!

---

### ✅ 4. 12 টা 8-bit Register

👉 রেজিস্টার মানে প্রসেসরের ভেতরে ছোট ছোট স্টোরেজ ঘর।

* ৬টা সাধারণ রেজিস্টার: B, C, D, E, H, L
* এগুলা ৮-বিট, কিন্তু দুইটা দুইটা জোড়া করে ১৬-বিট হিসেবেও ব্যবহার হয়
  যেমন: BC, DE, HL

**উদাহরণ:**

* B = 11H, C = 22H → BC = 1122H (16-bit)

---

### ✅ 5. Multiplexed Address/Data Bus (AD0–AD7)

👉 ৮ টা পিন একবার ডেটা ট্রান্সফার করে, আবার ঠিকানাও দেয় —
এখন ডেটা, পরক্ষণে ঠিকানা → তাই নাম **multiplexed**.

---

### ✅ 6. 8-bit Address Bus (A8–A15)

👉 অন্য ৮টি পিন শুধু **মেমোরি ঠিকানা** দিতে ব্যবহার হয়।

**মোট ঠিকানা দেয়া যায়:** 2^16 = 65536 লোকেশন (64KB মেমোরি)

---

### ✅ 7. Interrupts

👉 প্রসেসর যখন কাজ করছে, হঠাৎ বাইরের কোন ডিভাইস সিগন্যাল দিয়ে বলে:
"এইটা আগে করো!" — তখন যেটা হয়, সেটাই **Interrupt**।

* ৪টা maskable (বন্ধ করা যায়)
* ১টা non-maskable (বন্ধ করা যায় না)

---

### ✅ 8. DMA (Direct Memory Access)

👉 বাইরের ডিভাইস প্রসেসরের সাহায্য ছাড়াই সরাসরি মেমোরি তে ডেটা পাঠাতে পারে।

**উদাহরণ:** হার্ডডিস্ক → RAM

---

### ✅ 9. Serial-in / Parallel-out

👉 এটা ডেটা নেয় একটা তার দিয়ে (Serial-in)
আর দিতে পারে একসাথে ৮টা বিটে (Parallel-out)

## 🎓 উদাহরণ দিয়ে বোঝা যাক

### 🟩 উদাহরণ: `LDA 2050H`

👉 2050 নাম্বার ঠিকানা থেকে ডেটা A রেজিস্টারে নিয়ে আসো।

**ধাপ:**

1. Processor মেমোরি 2050H দেখে
2. ধরো, সেখানে লেখা আছে 5AH
3. তাহলে A = 5AH হয়ে যাবে

---

### 🟩 উদাহরণ: `MOV A, B`

👉 B রেজিস্টার এর মান A তে কপি করো
ধরো B = 32H → তাহলে `MOV A, B` দিলে A = 32H

---

### 🟩 উদাহরণ: `ADD C`

👉 A + C → আবার A তে রাখো
A = 20H, C = 10H → `ADD C` → A = 30H
