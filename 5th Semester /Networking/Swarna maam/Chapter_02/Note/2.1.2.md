## 🔄 2.1.2 Processes Communicating — সহজভাবে

### 🧠 Process মানে কী?
একটা **process** হলো এমন একটা **program** যা কোনো device-এ (host-এ) **চলছে**।

- যেমন: Chrome browser চালু করলে, সেটা একটা process
- Netflix app চালু করলে, সেটাও একটা process

---

### 🌍 Network Communication কীভাবে হয়?

যখন দুইটা device (host) একে অপরের সাথে network-এর মাধ্যমে কথা বলে, তখন আসলে **process ↔ process** message পাঠায়।

- **Sending process** → message পাঠায়
- **Receiving process** → message পায় এবং উত্তর দিতে পারে

📌 এই message আদান-প্রদান হয় **application layer**-এ।

---

## 👥 Client vs Server Process

### 🔹 Client:
- **যে process প্রথমে যোগাযোগ শুরু করে**
- যেমন: Browser → Web server-এ request পাঠায়

### 🔹 Server:
- **যে process অপেক্ষা করে, client-এর message পাওয়ার জন্য**
- যেমন: Web server → browser-এর request-এর উত্তর দেয়

📌 P2P-তে (যেমন BitTorrent), একটাই process কখনো client, কখনো server হতে পারে।  
যখন Peer A → Peer B-কে ফাইল চায়, তখন A = client, B = server।

---

## 🚪 Socket: Process-এর দরজা

### 🎯 কীভাবে message network-এ যায়?

প্রতিটা process message পাঠায় বা পায় **socket** এর মাধ্যমে।

- **Socket = দরজা**  
- Process message পাঠায় → socket দিয়ে network-এ যায়  
- Message পৌঁছায় → অন্য process-এর socket দিয়ে ভিতরে আসে

📌 Socket হলো **application layer ↔ transport layer** এর সংযোগ।

---

### 🧰 Developer কী নিয়ন্ত্রণ করতে পারে?

- Application developer socket-এর ওপরে control রাখে
- Transport layer-এর control কম, শুধু:
  - কোন transport protocol (TCP/UDP) ব্যবহার করবে
  - কিছু parameter (buffer size, segment size)

---

## 🏠 Addressing: Message কোথায় যাবে?

যেমন চিঠি পাঠাতে ঠিকানা লাগে, তেমনি network message পাঠাতে **host address + process identifier** লাগে।

### 🔹 দুইটা জিনিস দরকার:
1. **IP Address** → কোন device (host)  
2. **Port Number** → কোন process/socket

📌 উদাহরণ:
- Web server → Port 80
- Mail server → Port 25

---

## 🔁 সহজ উদাহরণ:

তুমি Chrome browser দিয়ে www.google.com-এ গেলে:

1. Chrome process → Google server-এর IP address + port 80-এ message পাঠায়
2. Google server process → message পায়, উত্তর দেয়
3. সব message socket দিয়ে যায় ↔ TCP/UDP ব্যবহার করে
